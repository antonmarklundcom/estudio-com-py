# S3 — Áreas depth (Sonnet, 2026-09-09)

## Built

- All 8 área records in `content/services.php` deepened to the plan §6.2 target: `includes` 5–6,
  `excludes` 2–3, `weNeed` 3–4, `sections` = "Qué hacer ahora" (2 paragraphs) + "Qué esperar"
  (Plazos / Costo), `faq` 4 questions in the visitor's words.
- `excludes` is the real gain: it was empty on most áreas, and every one of the 18 exclusions now
  names the área that *does* cover the thing ("La división de una herencia entre herederos: eso
  lo ve sucesiones"). All 18 point at an área that exists.
- The depth reaches all 56 área × ciudad pages through the generator, so this is 64 pages of
  copy from one file.
- `content/areas-ciudades.php` was not touched: all 56 generated records already sit inside the
  title/description budget, so the `$areas` table needed no correction.

## Decisions

- Costs and times stay structural, never numbers (plan §1.2): "el abogado le cotiza antes de
  empezar; estudio.com.py no cobra al usuario". A number here would be a claim nobody verified.
- `hero.lead` keeps "su ciudad" on exactly the five áreas that already had it and was not added
  to the other three — the área × ciudad generator substitutes the city name into that phrase,
  and adding it where it was absent would have changed 21 generated pages as a side effect.
- `guides` and `related` left untouched: S5 owns them.

## Known issues

- `./verify.sh` on this Windows machine is unreliable on long runs: the `php -S` dev server dies
  partway through the 86-page metadata sweep, after which every remaining check fails with empty
  bodies and 000 responses regardless of the diff. Seen on S2 as well. Re-running after
  `taskkill //F //IM php.exe` and with a private `VERIFY_PORT` passes; Linux CI has never shown
  it. Treat CI as authoritative and re-run locally before believing a failure that lands in
  `enviar.php` or the form checks when the diff touched neither.
- This phase ran with concurrent sessions on one working tree (an orchestration error on my part,
  not the phase's). One consequence is recorded in PR #5; nothing was lost.

Verification: CI `verify` green on PR #6 and on the merge commit (26s, 0 failures, Linux);
`./verify.sh` PASS locally on merged main in a clean environment (97 URLs, 86 pages, every title
and description unique); the `areas-ciudades` length check prints nothing across all 56 records
(seoTitle ≤ 60, description 120–155); "Qué no incluye" renders on all 8 área pages; 5 sampled
área × ciudad pages (luque/familia, asuncion/penal, capiata/laboral, lambare/marcas,
san-lorenzo/tributario) return 200 with FAQPage JSON-LD that parses; the diff names no price, no
day count and no institution outside MTESS, IPS, DINAPI, DNIT, DGRP and Ministerio Público, and
never says "nuestros abogados" or "nuestro estudio".
