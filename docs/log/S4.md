## Decisions

- Wrote the no-lawyer-yet answer once (as `about.text`/`about.credentials`
  wording) and reused the same sentence structure in `contact.steps` and
  `/terminos/`, rather than inventing three different phrasings — keeps the
  "facts must already be true elsewhere" constraint trivially satisfiable:
  every new sentence restates what `trust.empty` (O1) and `terminos`'s
  existing "Costo del servicio" section already say.
- `/privacidad/`'s retention sentence is deliberately duration-free ("mientras
  exista la posibilidad de derivarla ... y mientras haga falta para
  responder a consultas o reclamos") since no retention period is fixed
  anywhere in the repo and inventing one would violate plan §1.2.
- 404 city grid reuses `partials/service-card-grid.php` with a manually
  built `$gridCards` array (title/text/path/links) sourced from
  `content('segmentos')`, rather than adding a new partial — the grid
  partial already accepts that exact shape.
