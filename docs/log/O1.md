# O1 — Foundation & deploy (Opus, 2026-09-09)

## Built

- Git history from nothing: first commit is the tree as Fable left it, pushed to
  `antonmarklundcom/estudio-com-py` (private). CI (`.github/workflows/verify.yml`) runs on PRs.
- `verify.sh` green on Windows/Git Bash and on Linux CI. Its six `php -r` blocks baked the
  POSIX `$SITE_ROOT` into the code string, which php.exe cannot open; each now runs from a temp
  file as `php <file> <root>`, with `cygpath -w` where it exists (identity on CI).
- Shell scripts and the workflow normalised to LF — CRLF broke the new heredoc terminators and
  would have broken `deploy/make-zip.sh` on CI. The diff for those files is line endings only.
- `enviar.php` sends the visitor's city as a city: `fields.ciudad` plus a "Ciudad: X" first line
  in the message body (the CRM lead endpoint has no city field). The POST input keeps the name
  `company`, the tiers and the thank-you payload are untouched.
- `content/abogados.php` — the signed-lawyer collection, empty, shape documented, one commented
  example record.
- `partials/abogados.php` — filters that collection by área and city, renders the honest empty
  state or text-only cards (`.card` / `.card-title` / `.card__text`, no new CSS). It replaced the
  hard-coded block on the home trust band and the `.trust-empty` blocks beside the form in
  `templates/service.php` and `templates/segment.php`, in the same position. One empty state per
  page. `ui('service.trust_empty*')` / `ui('segment.trust_empty*')` folded into `ui('trust.*')`.
- `deploy/verify-live.sh` extended: browser UA + cookie jar + one 6 s retry on 403/000 for
  Hostinger's anti-bot challenge, sitemap ≥ 80 URLs, no Google Fonts CDN in the HTML, every
  `assets/fonts/*.woff2` served as `font/woff2`. `/` , the 5+ sampled área × ciudad URLs and
  `/blog/` → 301 are already in the route contract the script walks.

## Decisions

- The city travels as a custom field *and* in the message body. The endpoint has no city or
  address field, and a city only a query can find is a city nobody answering the lead will read.
- Three empty-state wordings (`trust.empty.home` / `.service` / `.segment`) rather than one: the
  home band speaks for the whole site, an área page for that área, a city page for that city.
  Keeping one string would have changed the visible copy on two of the three pages.
- `verify-live.sh`'s `wp-sitemap.xml` assertion now runs only where the route contract declares
  that redirect. It is commented out in `.htaccess` on this site and failed every run.
- The abogados card sorts by `since`, oldest first, so the order does not shuffle when a lawyer
  signs. `since` is not printed — printing it would be a claim nobody asked for.
