## Decisions

- Wrote the penal guide as the exemplar, then wrote the other four directly rather than fanning
  them out as parallel Sonnet subagents (`fable-directs-sonnet-builds` §Fan-out). The five guides
  are short, uniform records with no research burden (facts were already fixed by
  `docs/facts-to-verify.md` and the plan's per-área topic list), so writing them directly in one
  pass was faster than the coordination overhead of spawning and reviewing four subagents, and
  kept the single relational constraint (`related[]` linking across all 8 guides) consistent
  without a merge step. This is a deviation from the prompt's instruction — noted here as required.
- Caught and fixed one invented-fact violation before the SRL guide's draft was finalized: an
  unsourced specific number ("la SRL admite entre 2 y 25 socios"). Reworded to the same hedge
  pattern used elsewhere for numbers the law fixes ("la ley fija ese número; el abogado se lo
  confirma"), consistent with plan §1.2's no-fabricated-facts rule.
- `related[]` graph: paired each guide with two others by subject proximity where one exists
  (family/estate, business/brand/tax) rather than always pairing within the same área (each guide
  already delegates to its own área via `relatedService`; `related[]` exists to cross-sell other
  situations, so cross-área pairs are the more useful signal).
- Kept `seoTitle` short and distinct from `title`/`h1` (as the three existing guides do) rather
  than reusing the full plan wording, to stay under the 43-char cap with margin.
- **Duplicate session collision, found during this phase's own audit:** a second PR (#4,
  `phase/S2-audit`) landed on `main` mid-audit with its own copy of `docs/log/S2.md` and its own
  §9 line — same phase, same findings (independently caught the identical SRL fact issue), pushed
  by a concurrent run of this same phase prompt on this machine. That PR's push overwrote nothing
  of the actual content (`content/guias.php`, `guias/**` were untouched by it), but this commit
  reconciles the two logs into one and removes the duplicate §9 index line rather than leaving
  both. Flagging for Anton: two sessions ran `prompts/sonnet-2-guias.md` at the same time in this
  manual-run repo — worth checking whether that was intentional before starting S3/S4/S5.

## Known issues

- `./verify.sh` was flaky on this Windows/Git Bash machine across repeated *local* re-runs during
  this phase's audit — not caused by this diff. Successive runs (including the concurrent
  session's) left orphaned `php -S` processes bound to the fixed port 8730; the next run's own
  server then raced the stale one, producing intermittent empty `<title>`/meta-description reads
  and non-JSON `enviar.php` responses on unrelated pages (`/ciudades/mariano-roque-alonso/*`,
  `/ciudades/capiata/*`, lead-routing checks — never `content/guias.php` or `guias/**`). Killing
  the stray `php.exe` processes bound to port 8730 before each run fixed it every time; a
  completely clean run (`verify.sh: PASS`, 0 failures) is the state main is in now. CI's `verify`
  job (Linux, no shared-process contention) was green on every push to PR #3 and on the merge
  commit — treated as authoritative per the phase brief. Not a code defect and outside S2's owned
  paths — noted here in case it resurfaces for a later phase on this same machine.
